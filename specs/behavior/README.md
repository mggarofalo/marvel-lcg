# Behavior catalog

`adjudications.json` is the reviewed source-to-obligation decision record.
`catalog.json` is generated by joining those decisions to the current canonical
authority fingerprints. Neither file is generated from implementation code or
from the inherited draft feature files.

```bash
dotnet run --project tools/Marvel.Behavior.Index -- check
dotnet run --project tools/Marvel.Behavior.Index -- report
dotnet run --project tools/Marvel.Behavior.Index -- skeletons
```

`check` is read-only. `write` deliberately regenerates `catalog.json` after an
authority or adjudication change. `scaffold` replaces `adjudications.json` with
invalid `unreviewed` markers and is only a starting point for a new authority
universe; it never blesses a proposal.

Implementation status is separate from semantic disposition. `unverified`
means the later executable transcript issues have not admitted an engine claim.
Known unsupported rules name both their Plane work item and the exact
`RulesNotImplementedException` the negative transcript must observe.
