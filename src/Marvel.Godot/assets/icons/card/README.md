# B1 face glyphs

`D.svg`, `S.svg`, and `U.svg` preserve the canonical ChampionsIcons outlines
already used by the approved B1 reference and the packaged font. Their source
and unresolved redistribution provenance remain documented in
[`../../fonts/UPSTREAM.md`](../../fonts/UPSTREAM.md); these files do not establish
or claim a new license.

The other SVGs are original functional outlines from the approved Impact
Editions reference generator. They represent attack, thwart, defense, scheme,
hand size, health, boost, and aspect identity. They contain no external card art.

`support.svg`, `upgrade.svg`, `ready.svg`, and `exhausted.svg` are original
functional outlines for compact source tiles. Ready uses an upright card and a
check; exhausted uses a horizontal card and a Z. Their fixed bounds preserve the
tile footprint while distinguishing state without color.

The renderer applies ink or paper color to these white outlines. Resources use
the separate canonical resource assets and their independent semantic colors.
