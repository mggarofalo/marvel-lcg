# SCENARIO #2 - BATROC

Villain Deck: Batroc (A) Flip Batroc (A) to Batroc (B) for expert mode. Main Scheme Deck: Infiltrate A.I.M. Island Embassy, Locate Missing Person, Extract Captives Encounter Deck: Batroc, A.I.M. Science, Batroc’s Brigade, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The A.I.M. Science and Batroc’s Brigade sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
