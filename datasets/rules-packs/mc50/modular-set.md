# MODULAR SET

The S.H.I.E.L.D. Executive Board modular set can be used outside of the Agents of S.H.I.E.L.D. campaign as a modular encounter set. When used this way, place two secret counters on each Board Member environment during setup. This set does not count toward the required number of modular encounter sets for a scenario.
