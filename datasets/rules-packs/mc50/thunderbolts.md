# THUNDERBOLTS

<a id="q-when-resolving-the-ability-on-thunderbolt-backup-131b-what-happens-if-there-is-a-tie-for-minion-with-the-most-damage"></a>
## Q. When resolving the ability on Thunderbolt Backup (131B), what happens if there is a tie for minion with the most damage?

A. If two or more minions have the same amount of damage (including no damage), the first player chooses which of the tied minions to place under Thunderbolt Backup.
