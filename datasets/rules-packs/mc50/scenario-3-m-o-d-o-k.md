# SCENARIO #3 - M.O.D.O.K.

Villain Deck: M.O.D.O.K. (A) Flip M.O.D.O.K. (A) to M.O.D.O.K. (B) for expert mode. Main Scheme Deck: Upgrading Adaptoids Encounter Deck: M.O.D.O.K., Scientist Supreme, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Scientist Supreme set can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
