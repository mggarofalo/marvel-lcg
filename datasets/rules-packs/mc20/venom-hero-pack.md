# VENOM HERO PACK

<a id="new-keyword-patrol"></a>
## New Keyword: Patrol

While any minions with the patrol keyword are engaged with a player, that player cannot thwart the main scheme.

<a id="new-keyword-ranged"></a>
## New Keyword: Ranged

An attack with the ranged keyword ignores the retaliate keyword.

<a id="frequently-asked-questions"></a>
## Frequently Asked Questions

A: Because each copy of Enraged Symbiote is considered to be Venom’s nemesis minion, Venom will put all set-aside copies of Enraged Symbiote into play.
