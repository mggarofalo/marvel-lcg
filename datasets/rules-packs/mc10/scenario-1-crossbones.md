# SCENARIO #1 - CROSSBONES

Villain Deck: Crossbones (I), Crossbones (II) Remove Crossbones (I) and add Crossbones (III) for expert mode. Main Scheme Deck: Attack on Mount Athena, The Infinity Gem, The Getaway Encounter Deck: Crossbones set, Experimental Weapons set, Hydra Assault set, Weapon Master set, Legions of Hydra set, and Standard set. (The Legions of Hydra set and Standard set can be found in the Marvel Champions core-set.) The Hydra Assault and Weapon Master sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
