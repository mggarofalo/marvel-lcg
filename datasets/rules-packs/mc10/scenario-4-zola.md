# SCENARIO #4 - ZOLA

Villain Deck: Zola (I), Zola (II) Remove Zola (I) and add Zola (III) for expert mode. Main Scheme Deck: The Island of Dr. Zola, The Mad Doctor Encounter Deck: Zola set, Under Attack set, and Standard set. (The Under Attack and Standard sets can be found in the Marvel Champions core-set.) The Under Attack set can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
