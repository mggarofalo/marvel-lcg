# COMPETITIVE MODE

For players who want to test their mettle against a live opponent, the Civil War custom scenario expansion provides rules for an exciting new competitive mode! This mode can be played either 1v1 (one registration player against one resistance player) or 2v2 (two registration players against two resistance players).
