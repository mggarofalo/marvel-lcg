# SPIDER-WOMAN

Leader Deck: Spider-Woman (I), Spider-Woman (II) Remove Spider-Woman (I) and (II) and add Spider- Woman (III) and (IV) for expert mode. Main Scheme Deck: Open Rebellion, Neighborhood Protectors Encounter Deck: Spider-Woman, Spider-Man, Defenders, Hell’s Kitchen, Cloak & Dagger, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Defenders, Hell’s Kitchen, Cloak & Dagger, and Spider-Man sets can be removed from this scenario and/ or added to other scenarios when using the scenario customization rules.
