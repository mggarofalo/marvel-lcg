# CAPTAIN AMERICA

Leader Deck: Captain America (I), Captain America (II) Remove Captain America (I) and (II) and add Captain America (III) and (IV) for expert mode. Main Scheme Deck: Gathering Support, Secret Avengers Encounter Deck: Captain America, New Avengers, Secret Avengers, Namor, Atlanteans, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The New Avengers, Secret Avengers, Namor, and Atlanteans sets can be removed from this scenario and/ or added to other scenarios when using the scenario customization rules.
