# SCENARIO #1 - SABRETOOTH

Villain Deck: Sabretooth (I), Sabretooth (II) Remove Sabretooth (I) and add Sabretooth (III) for expert mode. Main Scheme Deck: Stalked by Sabretooth, The Injured Senator Encounter Deck: Sabretooth, Brotherhood, Mystique, and Standard sets. (The Standard set can be found in the Marvel Champions core set.) The Brotherhood and Mystique sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
