# SCENARIO #3 - MASTER MOLD

Villain Deck: Master Mold (I), Master Mold (II) Main Scheme Deck: The Sentinel Factory, Master Mold’s Agenda Encounter Deck: Master Mold, Sentinels, Zero Tolerance, and Standard sets. (The Standard set can be found in the Marvel Champions core set.) The Zero Tolerance set can be removed from this scenario and/or added to other scenarios when using the scenario customization rules. The Sentinels set may be used in other scenarios, but it is required when playing Master Mold.
