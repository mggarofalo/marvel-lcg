# INFINITES MODULAR SET

The Unus scenario requires the Infinites modular set, which includes the Gene Pool side scheme. Gene Pool has both the permanent and setup keywords, so it always begins the game in play and cannot leave play. Both Unus and the Infinite Soldier (included in the Infinites set) grow stronger or weaker depending on how much threat is on Gene Pool, so be careful not to let it stack up too high!
