# USING THE ‘POOL ASPECT

The ‘Pool aspect counts as an aspect for all gameplay purposes. You can customize any hero’s deck using the ‘Pool aspect as your chosen aspect following the deck customization rules found in Appendix I of the Rules Reference. Bringing Deadpools from across the multiverse into battle is a very risky proposition. When setting up a game in which at least one player is using the ‘Pool aspect, shuffle 1 copy of the Crisis of Infinite Deadpools (37) treachery card into the encounter deck. Set the rest of the Dreadpool modular encounter set aside. This encounter set is shuffled into the encounter deck when Crisis of Infinite Deadpools is revealed.
