# PER GROUP ICON ()

The  icon is used in the God of Lies scenario. During the scenario, each player joins a group of 1 to 4 players, and each group is assigned to a “pod” (see pages 10 and 13 for details). If the  icon is on a card in a group’s game area, that icon multiplies the value it is next to by the number of groups in the respective pod. If the  icon is on a card that is not in a specific group’s game area (such as the Worlds Collide main scheme), that icon multiplies the value it is next to by the total number of groups in the game.
