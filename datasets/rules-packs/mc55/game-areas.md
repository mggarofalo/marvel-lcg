# GAME AREAS

While playing God of Lies in Epic Multiplayer Mode, each player group is in its own game area. Unless explicitly stated otherwise, cards and components in one game area cannot affect another game area. Players cannot attack or defend enemies in other game areas, and they cannot target any game elements in other game areas. Each group plays the game simultaneously with each other group. This means that some groups may progress through their rounds faster than others, and that’s okay; there is no need to wait until all groups have reached the same point in the round before proceeding.
