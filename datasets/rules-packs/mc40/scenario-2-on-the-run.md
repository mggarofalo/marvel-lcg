# SCENARIO #2 - ON THE RUN

Villain Deck: Arclight (A), Blockbuster (A), Chimera (A), Greycrow (A), Harpoon (A), Riptide (A), Vertigo (A) Flip each villain (A) to its villain (B) side for expert mode. Main Scheme Deck: Gotta Get Away, Escaping with Hope Encounter Deck: On the Run, Military Grade, Mutant Slayers, Nasty Boys, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Military Grade and Nasty Boys sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules. The Mutant Slayers set may be used in other scenarios, but it is required when playing On the Run.
