# SIEGE

Villain Deck: Arclight (A), Blockbuster (A), Chimera (A), Greycrow (A), Harpoon (A), Riptide (A), Vertigo (A) Flip each villain (A) to its villain (B) side for expert mode. Main Scheme Deck: Knock, Knock; Mutant Massacre Encounter Deck: Morlock Siege, Military Grade, Mutant Slayers, and Standard encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Military Grade and Mutant Slayers sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
