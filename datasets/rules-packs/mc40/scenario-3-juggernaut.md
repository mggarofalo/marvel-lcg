# SCENARIO #3 - JUGGERNAUT

Villain Deck: Juggernaut (I), Juggernaut (II) Remove Juggernaut (I) and add Juggernaut (III) for expert mode. Main Scheme Deck: The Unstoppable Juggernaut Encounter Deck: Juggernaut, Hope Summers, Black Tom Cassidy, and Standard sets. (The Standard set can be found in the Marvel Champions core set.) The Black Tom Cassidy set can be removed from this scenario and/or added to other scenarios when using the scenario customization rules, but it is required when playing Juggernaut in campaign mode. The Hope Summers set may be used in other scenarios, but it is required when playing Juggernaut.
