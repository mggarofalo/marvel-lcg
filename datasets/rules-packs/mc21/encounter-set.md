# ENCOUNTER SET

The Infinity Gauntlet is one of the most powerful artifacts in the Marvel universe. To represent its unique and unprecedented power, the Infinity Gauntlet has its own encounter set for Marvel Champions: The Card Game. This special modular set can be used in most Marvel Champions: The Card Game scenarios by using the following rules: When using the Infinity Gauntlet set in a scenario, attach the Infinity Gauntlet attachment card to the villain during setup. If there is more than one villain (or no villain) in play at the start of the game, The Infinity Gauntlet set cannot be used. After attaching the Infinity Gauntlet to the villain, shuffle the six environment cards together and set them aside, facedown. This is the “ deck.” The deck has its own discard pile. When an environment is discarded, it is placed in the deck discard pile. If the deck is ever empty, shuffle the deck discard pile back into the deck. There is no built-in penalty for doing this. Each environment has a unique Special effect that is triggered by the Infinity Gauntlet when the attached villain activates. If there are no I environment cards in play when the villain activates, the Infinity Gauntlet’s ability places the top card of the deck into play instead.
