# SPIDER-MAN (MILES MORALES)

<a id="q-can-i-use-cards-from-the-spider-man-miles-morales-set-when-i-play-spider-man-peter-parker-and-vice-versa"></a>
## Q. Can I use cards from the Spider-Man (Miles Morales) set when I play Spider-Man (Peter Parker), and vice versa?

A. No. Cards related to an identity—identity-specific cards, obligation cards, and nemesis encounter set cards—may only be used alongside the identity with which they share a set icon.
