# SCENARIO #5 — VENOM GOBLIN

<a id="q-are-players-restricted-to-only-removing-threat-from-the-scheme-with-the-glider-counter"></a>
## Q. Are players restricted to only removing threat from the scheme with the glider counter?

A. No. Player cards that specify “the main scheme” can remove threat from any main scheme.

<a id="q-multiple-main-schemes-have-the-same-amount-of-threat-which-scheme-is-considered-to-have-the-least-or-most-threat-on-it"></a>
## Q. Multiple main schemes have the same amount of threat. Which scheme is considered to have the “least” or “most” threat on it?

A. Any time an encounter card targets a specific card and there are multiple eligible targets, the first player selects among the eligible options.

<a id="q-how-do-the-patrol-keyword-and-the-crisis-icon-interact-with-three-main-schemes"></a>
## Q. How do the patrol keyword and the crisis icon interact with three main schemes?

A. The patrol keyword prevents the engaged player from thwarting “the main scheme,” while the crisis icon prevents each player from removing threat from “the main scheme.” In both cases, per the glider counter rules, encounter effects that refer to “the main scheme” only refer to the scheme with the glider counter.
