# SCENARIO #3 - MYSTERIO

Villain Deck: Mysterio (I), Mysterio (II) Remove Mysterio (I) and add Mysterio (III) for expert mode. Main Scheme Deck: Maze of Mirrors (1A/1B), Edge of Reality (2A/2B) Encounter Deck: Mysterio, Personal Nightmare, Whispers of Paranoia, and Standard encounter sets. The Whispers of Paranoia modular set can be removed from this scenario and/or added to other scenarios when using scenario customization rules. The Personal Nightmare modular set can be used in other scenarios but is required while playing the Mysterio scenario.
