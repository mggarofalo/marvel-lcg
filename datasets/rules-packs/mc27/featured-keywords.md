# FEATURED KEYWORDS

<a id="hinder-x"></a>
## Hinder X

When a card with the hinder X keyword is revealed, place X threat on that card.

<a id="incite-x"></a>
## Incite X

When a card with the incite X keyword is revealed, place X threat on the main scheme.

<a id="patrol"></a>
## Patrol

While any minions with the patrol keyword are engaged with a player, that player cannot thwart the main scheme.

<a id="permanent"></a>
## Permanent

A card with the permanent keyword cannot leave play.

<a id="piercing"></a>
## Piercing

An attack with the piercing keyword discards any tough status cards from the target of the attack before dealing damage. Requirement (Resources) * A card with the requirement keyword cannot be played unless each resource of the specified type is spent while paying for that card’s cost.

<a id="setup"></a>
## Setup

A card with the setup keyword begins the game in play.

<a id="stalwart"></a>
## Stalwart

A character that has the stalwart keyword cannot be stunned or confused.

<a id="steady"></a>
## Steady

A character with the steady keyword can have one additional stunned status card and one additional confused status card. That character is not stunned unless they have two stunned status cards, and is not confused unless they have two confused status cards. After that character’s activation is replaced by a status card effect, remove all status cards of that type from that character.

<a id="team-up"></a>
## Team-Up

The team-up keyword names two characters. To include a card with the team-up keyword in your deck, your chosen identity must match one of the named characters. Additionally, a card with the team-up keyword cannot be played unless both of the named characters (identity or ally) are in play.

<a id="villainous"></a>
## Villainous

When a minion with the villainous keyword activates, give it a facedown boost card from the top of the encounter deck. When you resolve that minion’s activation, turn the boost card faceup and apply its boost icons to the minion’s stats for this activation. If the boost card has a boost ability, resolve its effects. Discard the boost card after the activation.

<a id="victory-x"></a>
## Victory X

When a card with the victory X keyword is defeated, place it in the victory display instead of its owner’s discard pile.
