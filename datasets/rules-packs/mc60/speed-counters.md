# SPEED COUNTERS

Speed counters placed on the main scheme represent the speed of the ongoing chase. The faster the villain flees, the harder it is to keep up with them and the greater the chance of the chase ending in a catastrophic accident. A speed counter gets added to the main scheme at the end of each round unless you are able to keep it clear of threat. There is no limit to the number of speed counters on the main scheme, and encounter cards in the deck get more punishing the more counters there are.
