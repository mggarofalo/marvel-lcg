# NEMESIS SETS

This scenario utilizes the heroes’ nemesis sets in a different way. During setup, each player is instructed to reveal their set-aside nemesis minion. If any player’s nemesis minion shares a title with a character in play (such as Echo’s nemesis minion, Kingpin), that nemesis minion is removed from the game and that player instead finds an minion in the encounter deck and reveals it. Several encounter cards in this scenario instruct a player to bring a card from their set-aside nemesis set into the game. Once a card has entered the game this way, it is treated as part of the encounter deck.
