# PROTECTION RACKET

Main Scheme Deck: Protection Racket (x5) Encounter Deck: Protection Racket, Disasters, Tracksuit Mafia, Standard, and chosen villain’s encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Disasters and Tracksuit Mafia sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
