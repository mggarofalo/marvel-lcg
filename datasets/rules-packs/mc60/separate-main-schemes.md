# SEPARATE MAIN SCHEMES

In this scenario, each player has their own main scheme, representing a local business that needs protection from the villain and their goons. When setting up the game in standard mode, players can look at the “1B” side of the main schemes when making their choice of which one to start with. Each main scheme is in the play area of the player who chose it. When a player plays an event or reveals a treachery that refers to “the main scheme,” that card only applies to the main scheme in that player’s play area. Cards in a player’s play area (identities, allies, upgrades, minions, etc.) that refer to “the main scheme” refer only to the main scheme in the same play area. Cards that are not in any player’s play area (the villain, side schemes, and environments) that refer to “the main scheme” apply to all main schemes. For example, a crisis icon () on a side scheme prevents threat from being removed from any main scheme, and an acceleration icon () adds 1 additional threat to each main scheme during step 1 of each villain phase. Cards and effects that refer to “a scheme,” including basic thwarts, can affect any main scheme in play. When an acceleration token would be placed on the main scheme, such as when the encounter deck is reset, place that acceleration token near the villain. Each acceleration token adds 1 additional threat to each main scheme during step 1 of each villain phase.
