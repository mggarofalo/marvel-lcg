# UNDERLING VILLAIN PLAY ORDER

As mentioned earlier, each scenario uses one of the five interchangeable villains. Each of these villains has the trait. For the players’ first playthrough, below is a recommended order to play against the villains. This order pits the heroes against increasingly complex villains as the campaign advances. Hammerhead Bullseye Electro Purple Man or Typhoid Mary On subsequent campaign playthroughs, players should randomly select the villain for each game.
