# THE RAFT BREAKOUT

Main Scheme Deck: The Raft Breakout Encounter Deck: The Raft Breakout, The Owl, Tombstone, Standard, and chosen villain’s encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Owl and Tombstone sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
