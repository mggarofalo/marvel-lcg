# KINGPIN

Villain Deck: Kingpin (A1) Remove Kingpin (A1) and add Kingpin (B1) for expert mode. Main Scheme Deck: The King’s Gambit, Endgame Encounter Deck: Kingpin, Tombstone, and Tracksuit Mafia encounter sets. (Important: This scenario does not use the Standard encounter set, but still uses the Expert encounter set in Expert Mode.) The Tombstone and Tracksuit Mafia sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
