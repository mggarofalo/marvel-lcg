# STOP THE PRESSES!

Main Scheme Deck: Stop the Presses! Encounter Deck: Stop the Presses!, Tombstone, Tracksuit Mafia, Standard, and chosen villain’s encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Tombstone and Tracksuit Mafia sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
