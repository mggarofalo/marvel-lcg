# ECHO

<a id="q-when-can-i-use-the-ability-on-photographic-reflexes-40-to-play-an-event-tucked-under-echo"></a>
## Q. When can I use the ability on Photographic Reflexes (40) to play an event tucked under Echo?

A. While Photographic Reflexes is in your hand, it can be used any time that you would be able to play the tucked event if the tucked event had been in your hand. For example, if the tucked event has an “Action” ability, you can use Photographic Reflexes any time you could take an action during the player phase. If the event is a “Response” ability, you can use Photographic Reflexes to play that event any time its ability would trigger.

<a id="q-what-happens-to-the-tucked-event-after-i-use-photographic-reflexes-40-to-play-it"></a>
## Q. What happens to the tucked event after I use Photographic Reflexes (40) to play it?

A. That event is placed in its owner’s discard pile.
