# THE GETAWAY

Main Scheme Deck: The Getaway Encounter Deck: The Getaway, Cops, Drive, Standard, and chosen villain’s encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Cops and Drive sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
