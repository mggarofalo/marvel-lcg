# ART MUSEUM HEIST

Main Scheme Deck: Art Museum Heist Encounter Deck: Art Museum Heist, Cops, The Owl, Standard, and the chosen villain’s encounter sets. (The Standard set can be found in the Marvel Champions core set.) The Cops and The Owl sets can be removed from this scenario and/or added to other scenarios when using the scenario customization rules.
