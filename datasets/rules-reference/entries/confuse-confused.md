# CONFUSE, CONFUSED

Confuse is a status that cancels a character’s next scheme or thwart.

<a id="confuse-confused-1"></a>
1. A confused status card resolves like the triggered ability: “**Forced Interrupt**: When this character would scheme or thwart, remove each confused status card from it instead.”

<a id="confuse-confused-2"></a>
2. If an ability “confuses” a character, give that character a confused status card.

<a id="confuse-confused-3"></a>
3. A character is confused if it has a confused status card.
    <a id="confuse-confused-3-1"></a>
    - A character with the steady keyword is confused only if it has two confused status cards.

<a id="confuse-confused-4"></a>
4. If a character has an ability stating that it “cannot be confused,” confused status cards cannot be placed on that character.

<a id="confuse-confused-5"></a>
5. If a confused identity or ally attempts to thwart or use a thwart ability, discard the confused card instead. Costs associated with the thwart attempt, including exhausting the character, must still be paid.
    <a id="confuse-confused-5-1"></a>
    - A confused character can attempt to thwart or use a thwart ability even if it has no valid target for a thwart.

<a id="confuse-confused-6"></a>
6. If a confused villain or minion would scheme, discard the confused status card instead.

<a id="confuse-confused-7"></a>
7. As the thwart action or scheme activation was replaced by the removal of the confused status card, that character is not considered to have thwarted or schemed.
