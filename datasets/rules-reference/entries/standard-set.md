# STANDARD SET

The standard set is an encounter set that is added to most scenarios.

<a id="standard-set-1"></a>
1. The standard set is not a modular encounter set and cannot be selected *(by the players or randomly)* when a scenario requires players to choose a modular encounter set to include in that scenario.

<a id="standard-set-2"></a>
2. Cards in the “Standard” classification are any cards that have the word “Standard” printed by the bottom of the card in its encounter set name area.
