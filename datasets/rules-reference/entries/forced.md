# FORCED

Forced is a bold trigger word. If the word “**Forced**” precedes a triggered ability, the ability’s initiation is mandatory.

<a id="forced-1"></a>
1. “**Forced Interrupt**” and “**Forced Response**” abilities must be resolved when their triggering conditions are met.

<a id="forced-2"></a>
2. “**Forced Action**” abilities can be triggered at any time during the player phase when a non-forced action ability could be triggered, but must be resolved before the player phase can end.

<a id="forced-3"></a>
3. If a forced ability requires one or more targets to resolve and it has no valid targets, it does not initiate.
    <a id="forced-3-1"></a>
    - Any costs that would have been paid to initiate the ability are not paid.

<a id="forced-4"></a>
4. For any given triggering condition, forced interrupts take priority and initiate before non-forced interrupts, and forced responses take priority and initiate before non-forced responses.

<a id="forced-5"></a>
5. If two or more forced abilities would initiate at the same moment, the first player determines the order in which the abilities initiate, regardless of who controls the cards bearing those abilities.

<a id="forced-6"></a>
6. Each forced ability must resolve as completely as possible before the next forced ability being triggered by the same triggering condition may initiate.
