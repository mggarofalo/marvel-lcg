# “AND”

The word “and” indicates that two or more effects within an ability resolve simultaneously.

<a id="and-1"></a>
1. Individual effects connected by “and” are not dependent on each other. Resolve as much of each effect as possible.

<a id="and-2"></a>
2. Each effect connected by “and” can be canceled or prevented independently.
