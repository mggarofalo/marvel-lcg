# PHYSICAL RESOURCE

A physical resource ([physical]) is one of the four types of resources.

<a id="physical-resource-1"></a>
1. Physical resources can be spent to pay the resource cost of cards and abilities.

<a id="physical-resource-2"></a>
2. Some card abilities specifically require physical resources to be spent in order to resolve their effects.
