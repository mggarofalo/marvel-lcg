# STALWART

A character that has the stalwart keyword cannot be stunned or confused.

<a id="stalwart-1"></a>
1. The stalwart keyword is equivalent to the following constant ability: “This character cannot have confused or stunned status cards.”

<a id="stalwart-2"></a>
2. If a character gains the stalwart keyword while they have a stunned and/or confused status card, each stunned and/or confused status card is removed from that character.
