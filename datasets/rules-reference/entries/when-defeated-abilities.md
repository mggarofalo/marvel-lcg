# WHEN DEFEATED ABILITIES

A when defeated ability is a type of triggered ability, indicated by the bold “**When Defeated**” timing trigger.

<a id="when-defeated-abilities-1"></a>
1. The “**When Defeated**” timing trigger is equivalent to the following trigger: “**Forced Interrupt**: When this card is defeated...”

<a id="when-defeated-abilities-2"></a>
2. When a villain stage, side scheme, main scheme stage, ally, or minion is defeated, all “**When Defeated**” abilities on the card resolve.
    <a id="when-defeated-abilities-2-1"></a>
    - A defeated card leaves play after its “**When Defeated**” ability is resolved, if any.
