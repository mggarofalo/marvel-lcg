# INCITE X

When a card with the incite X keyword is revealed, place X threat on the main scheme. *(X is the value next to the incite keyword.)*

<a id="incite-x-1"></a>
1. The incite X keyword is equivalent to the following triggered ability: “**When Revealed**: Place X threat on the main scheme.”
