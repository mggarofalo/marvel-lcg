# MODULAR ENCOUNTER SET

Cards belonging to a “modular encounter set” *(or sometimes “modular set”)* are a classification of encounter card that can be added to and/or removed from nearly any scenario.

<a id="modular-encounter-set-1"></a>
1. During game setup, many scenarios will instruct the players on how many modular encounter sets must be included in that scenario. Depending on the scenario, some modular encounter sets are required, while others can be chosen by the players.

<a id="modular-encounter-set-2"></a>
2. If a modular encounter set is added to a scenario, it is done so as an entire set. Unless specific scenario rules state otherwise, individual cards from a modular encounter set cannot be included in a scenario without the rest of that set.

<a id="modular-encounter-set-3"></a>
3. A modular encounter set card is designated by the modular encounter set’s name with which it is associated printed at the bottom of the card in its encounter set name area.
