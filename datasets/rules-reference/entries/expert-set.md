# EXPERT SET

The expert set is an encounter set that is added to scenarios during expert mode.

<a id="expert-set-1"></a>
1. The expert set is not a modular encounter set and cannot be selected *(by the players or randomly)* when a scenario requires players to choose a modular encounter set to include in that scenario.

<a id="expert-set-2"></a>
2. Cards in the “Expert” classification are any cards that have the word “Expert” printed by the bottom of the card in its encounter set name area.
