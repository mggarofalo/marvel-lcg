# LEAVES PLAY

The phrase “leaves play” refers to any time when a card transitions from an in-play area to an out-of-play area. Defeating a character, discarding a card from play, placing a card in the victory display, or removing a card from the game are all different means by which a card can leave play.

<a id="leaves-play-1"></a>
1. When a card leaves play, there is no memory of its previous state and it is considered to be a new copy of the card.

<a id="leaves-play-2"></a>
2. When a non-villain card leaves play:
    <a id="leaves-play-2-1"></a>
    - Discard each card attached to or tucked under that card.
    <a id="leaves-play-2-2"></a>
    - Discard each boost card given to that card.
    <a id="leaves-play-2-3"></a>
    - Return each token and status card on that card to the supply.
