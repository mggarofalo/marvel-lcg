# HEAL

If an ability heals a character, damage the character has sustained can be removed from the character.

<a id="heal-1"></a>
1. A heal effect can only bring a character to its maximum hit points, unless the effect explicitly states it can bring the character above its maximum.

<a id="heal-2"></a>
2. Effects that move damage off of a character are considered to heal that character.
