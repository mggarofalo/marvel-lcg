# LINKED (CARD TITLE)

Cards with the linked keyword cannot be included in any deck. Instead, they are set aside at the start of the game if any deck includes the card that brings the linked cards into play (indicated in the parentheses following the keyword).

<a id="linked-card-title-1"></a>
1. The linked (card title) keyword is equivalent to the following constant ability: “Set this card aside during setup. This card does not count toward your deck size.”

<a id="linked-card-title-2"></a>
2. Linked cards do not count toward the minimum or maximum deck size.

<a id="linked-card-title-3"></a>
3. The number of linked cards set aside during setup is equal to the number of those cards included in the product from which the linked card came.
    <a id="linked-card-title-3-1"></a>
    - If multiple decks contain the same card named on one or more linked cards, set aside the appropriate number of cards for each deck that contains the named card.

<a id="linked-card-title-4"></a>
4. When a player takes control of a card with the linked keyword, that player becomes the owner of that card.
