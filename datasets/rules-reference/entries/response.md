# RESPONSE

A response ability is a type of triggered ability, indicated by the bold “**Response**” timing trigger. Response abilities may be resolved after the specified triggering condition occurs, as described in the response’s ability text.

<a id="response-1"></a>
1. Players can only trigger response abilities on cards they control or on encounter cards.
    <a id="response-1-1"></a>
    - Players cannot trigger response abilities on obligations in other players’ play areas.

<a id="response-2"></a>
2. Multiple responses may be triggered from the same triggering condition, but each response may only be triggered once per occurrence of the triggering condition.
    <a id="response-2-1"></a>
    - Multiple copies of a card with a response can each be triggered by the same triggering condition.

<a id="response-3"></a>
3. If single effect causes multiple triggering conditions to occur, responses to each of those triggering conditions can be resolved in any order. *(For example, if an attack triggers both “after you attack” and “after you defeat” responses, those responses can be resolved in any order.)*

<a id="response-4"></a>
4. Once all players decide they do not wish to resolve any *(further)* responses to a triggering condition, *(further)* responses to that instance of that triggering condition cannot be used.
