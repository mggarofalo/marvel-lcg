# “CANNOT”

The word “cannot” is absolute and cannot be countermanded by other abilities or effects.

<a id="cannot-1"></a>
1. If two abilities conflict, the ability with “cannot” takes precedence.

<a id="cannot-2"></a>
2. If two rules conflict, the rule with “cannot” takes precedence.

<a id="cannot-3"></a>
3. An ability can override a rule with “cannot” per the Golden Rules.

**See also:** [The Golden Rules](the-golden-rules.md), [Target](target.md)
