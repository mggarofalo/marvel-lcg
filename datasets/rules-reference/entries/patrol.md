# PATROL

While a minion with the patrol keyword is engaged with a player, that player cannot use cards they control to thwart the main scheme.

<a id="patrol-1"></a>
1. The patrol keyword is equivalent to the following constant ability: “The engaged player cannot thwart the main scheme.”
