# RETALIATE X

After a character with the retaliate X keyword is attacked, deal X damage to the attacker. *(X is the value next to the retaliate keyword.)*

<a id="retaliate-x-1"></a>
1. The retaliate X keyword is equivalent to the following triggered ability: “**Forced Response**: After this character is attacked, deal X damage to the attacker.”

<a id="retaliate-x-2"></a>
2. The character with retaliate X must be in play after the attack resolves to deal this damage.
