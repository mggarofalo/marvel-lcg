# ACCELERATION ICON

An acceleration icon represents additional forces that are advancing the villain’s nefarious plans. During step one of the villain phase, place X additional threat on the main scheme, where X is the number of acceleration icons in play.

<a id="acceleration-icon-1"></a>
1. Each acceleration icon is equivalent to the following constant ability: “During the Place Threat step of the villain phase, place 1 additional threat on the main scheme.”

<a id="acceleration-icon-2"></a>
2. An acceleration icon can be removed from play by defeating the encounter card it is printed on.

<a id="acceleration-icon-3"></a>
3. Accleration icons are not considered acceleration tokens, and vice versa.
