# IDENTITY-SPECIFIC CARD

Cards in the “identity-specific” classification *(also sometimes called “hero-specific”)* are cards that belong to an identity’s set of accompanying cards.

<a id="identity-specific-card-1"></a>
1. A player’s deck must include each identity-specific card associated with their chosen identity card. The exact quantity of each card in that identity-specific set must be included in the deck.

<a id="identity-specific-card-2"></a>
2. Identity-specific cards *(along with obligation cards and nemesis encounter set cards)* may only be used alongside an identity if those cards share a set icon with that identity.

<a id="identity-specific-card-3"></a>
3. An identity-specific card is designated by the identity icon printed in the bottom right corner of the card.
    <a id="identity-specific-card-3-1"></a>
    - Identity cards are identity-specific cards.
