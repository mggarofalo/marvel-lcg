# FLIP

When instructed to flip a card, turn that card upside down so that the face that was faceup is now facedown.

<a id="flip-1"></a>
1. A foldable, “three-sided” card is considered to have flipped any time the faceup side of the card changes.

<a id="flip-2"></a>
2. When a card flips, if the new faceup side of that card has:
    <a id="flip-2-1"></a>
    - The same card type as the previous face, the card retains all attached cards, tucked cards, status cards, and tokens.
    <a id="flip-2-2"></a>
    - A different card type from the previous face, all attached cards, tucked cards, status cards, and tokens are discarded from the card.
