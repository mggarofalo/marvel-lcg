# CRISIS ICON

While at least one crisis icon is in play, threat cannot be removed from the main scheme by player cards.

<a id="crisis-icon-1"></a>
1. Each crisis icon is equivalent to the following constant ability: “Player cards cannot remove threat from the main scheme.”

<a id="crisis-icon-2"></a>
2. Abilities on encounter cards are not affected by the crisis icon.
