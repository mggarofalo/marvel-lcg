# VILLAIN DEFEAT

If the villain’s hit point dial is reduced to zero, the players have defeated that stage of the villain. Remove the current stage of the villain deck from the game. The next sequential stage of the villain deck is revealed. Set the villain’s hit point dial as indicated by that stage. **If the final stage of the villain deck is defeated, the players win the game.**

<a id="villain-defeat-1"></a>
1. The revealing of a villain cannot be canceled.

<a id="villain-defeat-2"></a>
2. Excess damage that is dealt to defeat a villain stage does not carry over to the new stage.

<a id="villain-defeat-3"></a>
3. If the new stage of the villain has the same title as the previous stage:
    <a id="villain-defeat-3-1"></a>
    - The new stage of the villain is considered the same character as the defeated stage for purposes of card abilities *(such as the retaliate X keyword)*.
    <a id="villain-defeat-3-2"></a>
    - Attachments, upgrades, status cards, counters, and non-damage tokens on a villain carry over to the new stage.
    <a id="villain-defeat-3-3"></a>
    - If the villain was defeated while activating, the villain resumes that activation using the new villain stage.

<a id="villain-defeat-4"></a>
4. If the new stage of the villain has a different title from the previous stage:
    <a id="villain-defeat-4-1"></a>
    - The new stage of the villain **not** is considered the same character as the defeated stage for purposes of card abilities.
    <a id="villain-defeat-4-2"></a>
    - Attachments, upgrades, status cards, counters, and non-damage tokens do **not** carry over to the new stage.
    <a id="villain-defeat-4-3"></a>
    - If the villain was defeated while activating, the activation ends without resolving.
