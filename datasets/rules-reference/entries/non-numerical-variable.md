# NON-NUMERICAL VARIABLE

If a non-numerical variable *(such as a letter or other symbol)* is defined to have a numerical value *(such as a card ability assigning a value to ‘X’)*, treat that variable as the defined value. If the variable is not defined *(for instance, if the ability defining it has been blanked)*, treat that variable as being equal to 0.

<a id="non-numerical-variable-1"></a>
1. For costs involving the letter X, the value of X is defined by card ability or player choice, after which the amount paid may be modified by effects without changing the value of X.
