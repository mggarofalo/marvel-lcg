# PERMANENT

A card with the permanent keyword cannot be defeated, leave play, or have any part of its text box blanked, except by card abilities in the same set *(hero set, scenario set, or modular set)*. *(For example, an ability on a hero card can cause a permanent card within that hero’s set to leave play.)*

<a id="permanent-1"></a>
1. The permanent keyword is equivalent to the following constant ability: “Set this card aside during setup. Effects on cards not from this card’s set cannot defea this card, remove this card from play, or blank any part of its text box.”

<a id="permanent-2"></a>
2. Permanent cards are set aside before step 1 of setup and are put into play later by abilities on other cards.

<a id="permanent-3"></a>
3. Permanent cards do not count towards a player’s minimum or maximum deck size.

<a id="permanent-4"></a>
4. Permanent cards are not valid targets for card effects that would cause the permanent card to leave play.
    <a id="permanent-4-1"></a>
    - If a permanent card would be targeted by such an effect *(for example, “discard the lowest-cost support you control”)*, that effect instead targets the non-permanent card that fits its criteria.

<a id="permanent-5"></a>
5. If the card to which a permanent attachment was attached leaves play, resolve that attachment’s “attach to” text. If it has none or that text does not have a valid target, remove the attachment from the game.

<a id="permanent-6"></a>
6. If a player is eliminated from the game while a non-attachment permanent card they do not own is in their play area, remove that permanent card from the game.
