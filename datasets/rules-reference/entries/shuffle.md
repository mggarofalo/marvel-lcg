# SHUFFLE

Shuffling is the game function of randomizing the contents of a deck.

<a id="shuffle-1"></a>
1. If a player is instructed to shuffle a deck, that deck must be randomized to the point where no player within the game can ascertain the order of the cards within that deck.

<a id="shuffle-2"></a>
2. Any time a deck is searched by a game step or card ability, that deck is shuffled after the game step or card ability completes its resolution.
