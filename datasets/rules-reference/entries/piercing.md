# PIERCING

An attack with the piercing keyword discards any tough status cards from the attacked character before dealing damage. The piercing keyword is equivalent to the following

<a id="piercing-1"></a>
1. ability: “Before this attack deals damage to a character, discard each tough status card from that character.”

<a id="piercing-2"></a>
2. If an attack with the piercing keyword would deal no damage to the attacked character, it does not discard tough status cards from that character.
