# GAME ELEMENT

A game element is a component or person involved in playing a game of **Marvel Champions**. All of the following are game elements:

<a id="game-element-1"></a>
1. Cards

<a id="game-element-2"></a>
2. Decks

<a id="game-element-3"></a>
3. Discard Piles

<a id="game-element-4"></a>
4. Hands (of cards)

<a id="game-element-5"></a>
5. Hit Point Dials

<a id="game-element-6"></a>
6. Players

<a id="game-element-7"></a>
7. Tokens
