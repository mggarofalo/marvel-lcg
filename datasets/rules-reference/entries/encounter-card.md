# ENCOUNTER CARD

There are eight encounter card types: attachment cards, environment cards, minion cards, main scheme cards, obligation cards, side scheme cards, treachery cards, and villain cards.

<a id="encounter-card-1"></a>
1. Encounter cards belong to various classifications, such as scenario-specific encounter cards or modular set encounter cards.

<a id="encounter-card-2"></a>
2. Most encounter cards have an orange card back.
