# TOUGH

Tough is a status that prevents a character from taking damage.

<a id="tough-1"></a>
1. A tough status card resolves like the triggered ability: “**Forced Interrupt**: When this character would take damage, remove a tough status card from it instead.”

<a id="tough-2"></a>
2. If a character with a tough status card would take any amount of damage, prevent all of that damage and discard a tough status card from that character instead.
    <a id="tough-2-1"></a>
    - A character with multiple tough status cards discards only one tough status card each time it would take damage.
    <a id="tough-2-2"></a>
    - When a hero with a tough status card defends an attack, they reduce the damage from the attack by their DEF first. If the damage is reduced to 0, the hero does not lose their tough status card.

<a id="tough-3"></a>
3. As a tough status card prevents damage fully, the character who had the tough status card is not considered to have taken damage.
