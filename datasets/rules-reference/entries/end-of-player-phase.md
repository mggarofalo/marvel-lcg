# END OF PLAYER PHASE

To end the player phase, perform the following steps: 1. In player order, each player may discard any number of cards from their hand, and must discard down to their hand size if they have more cards than their hand size. 2. Each player simultaneously draws up to their hand size. 3. Each player simultaneously readies all of their cards. Ready each exhausted encounter card. 4. Any effects that last “until the end of the [player] phase” end. 5. Resolve any “when/after the [player] phase ends” effects.
