# STUN, STUNNED

Stun is a status that cancels a character’s next attack.

<a id="stun-stunned-1"></a>
1. A stunned status card resolves like the triggered ability: “**Forced Interrupt**: When this character would attack, remove each stunned status card from it instead.”

<a id="stun-stunned-2"></a>
2. If an ability “stuns” a character, give that character a stunned status card.

<a id="stun-stunned-3"></a>
3. A character is stunned if it has a stunned status card.
    <a id="stun-stunned-3-1"></a>
    - A character with the steady keyword is stunned only if it has two stunned status cards.

<a id="stun-stunned-4"></a>
4. If a character has an ability stating that it “cannot be stunned,” stunned status cards cannot be placed on that character.

<a id="stun-stunned-5"></a>
5. If a stunned identity or ally attempts to attack or use an attack ability, discard the stunned card instead. Costs associated with the attack attempt, including exhausting the character, must still be paid.
    <a id="stun-stunned-5-1"></a>
    - A stunned character can attempt to attack or use an attack ability even if it has no valid target for an attack.

<a id="stun-stunned-6"></a>
6. If a stunned villain or minion would attack, discard the stunned status card instead.

<a id="stun-stunned-7"></a>
7. As the attack action or attack activation was replaced by the removal of the stunned status card, that character is not considered to have attacked.
