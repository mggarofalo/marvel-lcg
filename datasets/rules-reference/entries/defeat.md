# DEFEAT

If a character has zero or fewer remaining hit points, or if a side scheme has no threat on it, it is defeated.

<a id="defeat-1"></a>
1. If an ally, minion, or side scheme is defeated, it is discarded.

<a id="defeat-2"></a>
2. If an identity or stage of the villain is defeated, it is removed from the game.
