# VICTORY X

When a card with the victory X keyword leaves play under the following conditions, place it in the victory display instead of its owner’s discard pile:

<a id="victory-x-1"></a>
1. The victory X keyword is equivalent to the following) ability based on the card with the keyword:
    <a id="victory-x-1-1"></a>
    - Character or side scheme: “**When Defeated**: Add this card to the victory display.”
    <a id="victory-x-1-2"></a>
    - Attachment: “**Forced Interrupt**: When the attached card is defeated, add this card to the victory display.”
    <a id="victory-x-1-3"></a>
    - Card with the uses (X “type”) keyword: “If there are no all-purpose counters on this card, add this card to the victory display instead of discarding it.”

<a id="victory-x-2"></a>
2. A character or side scheme with the victory X keyword is placed in the victory display when it is defeated.

<a id="victory-x-3"></a>
3. An attachment or upgrade with the victory X keyword is placed in the victory display when the card to which it is attached is defeated. *(The card the attachment or upgrade was attached to is discarded as normal.)*

<a id="victory-x-4"></a>
4. A card with both the victory X and uses (X “type”) keywords is placed in the victory display when its last all-purpose counter is removed from it. While in the victory display, X indicates how many victory points that card is worth. *(X is the value next to the victory keyword.)*

<a id="victory-x-5"></a>
5. Some scenarios or campaigns may count the number of victory points in the victory display.
