# LABELED ABILITY

A labeled ability is a triggered ability with a parenthetical following its bold trigger text that designates that ability as an attack, defense, and/or thwart.

<a id="labeled-ability-1"></a>
1. The identity of the player using the labeled ability is considered to be performing the labeled effect when the labeled ability begins resolving *(after costs have been paid)*.

<a id="labeled-ability-2"></a>
2. When a player resolves an ability labeled “*(attack),*” that ability is considered to be an attack made by tha player’s identity.

<a id="labeled-ability-3"></a>
3. When a player resolves an ability labeled “*(defense),*” that ability is considered to be a defense made by that player’s identity.
    <a id="labeled-ability-3-1"></a>
    - When such an ability is initiated during an attack, the player’s identity becomes the defender of that attack.

<a id="labeled-ability-4"></a>
4. When a player resolves an ability labeled “*(thwart),*” that ability is considered to be a thwart made by that player’s identity.

<a id="labeled-ability-5"></a>
5. When a player resolves an ability with multiple labels, that ability is considered to be each of the labeled ability types, all made by that player’s identity.

<a id="labeled-ability-6"></a>
6. If a player triggers a labeled ability while their identity has one or more status cards that cancel any of the labeled ability types, the entire ability *(except for its costs)* is canceled.
    <a id="labeled-ability-6-1"></a>
    - That identity is not considered to have attacked, defended, or thwarted.
    <a id="labeled-ability-6-2"></a>
    - Each status card on the player’s identity that cancels any of the labeled ability’s types is removed when that ability is canceled. *For example, an ability labeled “*(attack/thwart)*” would remove both a confused status and a stunned status from the identity of the player who triggered the ability.*
