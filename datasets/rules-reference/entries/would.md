# “WOULD”

The word “would” is used to define the triggering condition of some interrupt abilities, and establishes a higher timing priority for those abilities than interrupts to the same triggering condition without the word “would.”

<a id="would-1"></a>
1. If an interrupt to a triggering condition that would occur changes the nature of that which is about to occur *(such as through a replacement effect)*, no further interrupts to the original trigger may be used since the resolution of that trigger is no longer valid. *For example, an interrupt that states “when a character would be defeated” triggers before an interrupt that states “when a character is defeated.”*
