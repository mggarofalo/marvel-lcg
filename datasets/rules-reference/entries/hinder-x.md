# HINDER X

A card with the hinder X keyword enters play with X threat on it. *(X is the value next to the hinder keyword.)*

<a id="hinder-x-1"></a>
1. The hinder X keyword is equivalent to the following constant ability: “This card enters play with X threat on it.”

<a id="hinder-x-2"></a>
2. This threat is in addition to any threat it normally enters play with, such as a side scheme’s starting threat.
