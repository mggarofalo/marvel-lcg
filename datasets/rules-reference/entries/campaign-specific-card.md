# CAMPAIGN-SPECIFIC CARD

Cards in the “campaign-specific” classification are cards that belong to a campaign’s set of accompanying cards.

<a id="campaign-specific-card-1"></a>
1. Campaign-specific cards can only be used during a campaign from the same product *(determined by that product’s set icon)*.

<a id="campaign-specific-card-2"></a>
2. A campaign’s rules determine how players utilize campaign-specific cards within that campaign.

<a id="campaign-specific-card-3"></a>
3. A campaign-specific card is designated by the word “Campaign” printed at the bottom of the card in its encounter set name area.
