# SCHEME (CARD TYPE)

The word “scheme” denotes three different card types: main schemes, player side schemes, and side schemes.

<a id="scheme-card-type-1"></a>
1. If a card ability places threat on or removes threat from “a scheme,” the player resolving that ability chooses which scheme—main scheme or side schemes—that ability affects.
