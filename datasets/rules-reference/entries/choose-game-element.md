# CHOOSE (GAME ELEMENT)

The phrase “choose a [game element]” *(such as an ally, a minion, or a scheme)* indicates that a player must select a game element that meets the specific requirements of an ability.

<a id="choose-game-element-1"></a>
1. The player resolving the ability that uses the word “choose” is the player who makes the choice specified by the card.

<a id="choose-game-element-2"></a>
2. If a player card ability requires the choosing of one or more targets, and there are no valid targets for any part of the ability, the ability cannot be initiated.

<a id="choose-game-element-3"></a>
3. If multiple targets are required to be chosen by the same player, simultaneously choose as many as are available, to a maximum of the specified number.
    <a id="choose-game-element-3-1"></a>
    - The same target cannot be chosen multiple times this way.

<a id="choose-game-element-4"></a>
4. An effect that can choose “any number” of targets does not successfully resolve if zero of those targets are chosen. s
