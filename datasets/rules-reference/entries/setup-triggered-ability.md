# SETUP (TRIGGERED ABILITY)

“**Setup**” is a type of triggered ability that is resolved during setup.

<a id="setup-triggered-ability-1"></a>
1. Setup abilities are mandatory.

<a id="setup-triggered-ability-2"></a>
2. Setup abilities on encounter cards are resolved during the “Resolve Scenario Setup and When Revealed Abilities” step of setup.

<a id="setup-triggered-ability-3"></a>
3. Setup abilities on player cards are resolved during the “Resolve Character Setup Abilities” step of setup.

**See also:** [Triggered Ability](triggered-ability.md), [Appendix II: Setup](appendix-ii-setup.md)
