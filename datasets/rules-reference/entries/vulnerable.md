# VULNERABLE

When a character with vulnerable becomes confused or stunned, that character is immediately discarded *(without being defeated)*.

<a id="vulnerable-1"></a>
1. The vulnerable keyword is equivalent to the following triggered ability: “**Forced Interrupt**: When this character becomes confused or stunned, discard it.”

<a id="vulnerable-2"></a>
2. If a character with the vulnerable keyword would simultaneously take enough damage to defeat it and become either confused or stunned, it is discarded before the damage is applied and is not considered defeated.

<a id="vulnerable-3"></a>
3. If a character has both the steady and vulnerable keywords, the vulnerable keyword does not take effect until that character has two confused or two stunned status cards.

**See also:** [Confuse](confuse-confused.md), [Steady](steady.md), [Stun](stun-stunned.md)
