# ACCELERATION TOKEN

Acceleration tokens are functionally equivalent to acceleration icons *(but are not considered acceleration icons)*. They are placed next to the main scheme as a reminder to add X additional threat to the main scheme during step one of the villain phase, where X is the number of acceleration tokens in play. Acceleration tokens enter play through one of two effects:

<a id="acceleration-token-1"></a>
1. If the encounter deck is empty, place one acceleration token next to the main scheme.

<a id="acceleration-token-2"></a>
2. Card effects may instruct the players to add an acceleration token to play.
    <a id="acceleration-token-2-1"></a>
    - Acceleration tokens placed on cards other than the main scheme still add threat to the main scheme during step one of the villain phase. Acceleration tokens on the main scheme cannot be removed from play. Unlike other tokens, when a main scheme card leaves play, the acceleration token does not get discarded.

<a id="acceleration-token-3"></a>
3. Acceleration tokens placed on cards other than the main scheme are removed from play when the card they are placed on leaves play.

<a id="acceleration-token-4"></a>
4. Accleration tokens are not considered acceleration icons, and vice versa.
