# WILD RESOURCE

A wild resource ([wild]) is one of the four types of resources.

<a id="wild-resource-1"></a>
1. Wild resources can be spent to pay the resource cost of cards and abilities. When a player generates a wild resource ([wild]), they may specify which resource type *(energy, mental, physical, or wild)* it is being used as.
    <a id="wild-resource-1-1"></a>
    - When a card that generates a wild resource has its resources doubled, each of its wild resources can be declared a different type.

<a id="wild-resource-2"></a>
2. Some card abilities specifically require wild resources to be spent in order to resolve their effects.

<a id="wild-resource-3"></a>
3. When resources are not being generated for a cost, a wild resource does not have any characteristic other than “wild resource.” In such contexts, wild resources cannot be interpreted as any of the other resource types.
