# KEYWORDS

A keyword is an attribute that conveys specific rules to its card.

<a id="keywords-1"></a>
1. If a card gains multiple instances of a keyword, any additional instances have no effect unless that keyword is followed by a number *(e.g. Hinder X, Retaliate X)*, in which case the numbers for each instance are added together. The following keywords are used in the game:

<a id="keywords-2"></a>
2. Alliance**: When a player declares their intention to play an alliance card, any player(s) may help pay the costs for that card. (**See**: Alliance)

<a id="keywords-3"></a>
3. Assault**: When a character makes a basic thwart against a scheme with the assault keyword, that character uses its ATK instead of its THW. (**See**: Assault)

<a id="keywords-4"></a>
4. Form**: A card with the form keyword grants an identity a unique form. (**See**: Form)

<a id="keywords-5"></a>
5. Guard**: While a minion with guard is engaged with a player, that player cannot attack the villain. (**See**: Guard)

<a id="keywords-6"></a>
6. Hinder X**: A card with the hinder X keyword enters play with X threat on it. (**See**: Hinder X)

<a id="keywords-7"></a>
7. Incite X**: When a player reveals a card with incite X, that player places X threat on the main scheme. (**See**: Incite X)

<a id="keywords-8"></a>
8. Linked (Card Title)**: Cards with the linked keyword are set aside until the card named in parentheses brings the linked card into the game. (**See**: Linked (Card Title))

<a id="keywords-9"></a>
9. Overkill**: Excess damage from attacks with overkill are dealt to the identity or villain. (**See**: Overkill)

<a id="keywords-10"></a>
10. Patrol**: While a minion with patrol is engaged with a player, that player cannot thwart the main scheme. (**See**: Patrol)

<a id="keywords-11"></a>
11. Peril**: While a player is resolving a card with peril, other players cannot help that player. (**See**: Peril)

<a id="keywords-12"></a>
12. Permanent**: Cards with permanent cannot leave play. (**See**: Permanent)

<a id="keywords-13"></a>
13. Piercing**: Attacks with piercing discard tough status cards from the attacked character before damage is dealt. (**See**: Piercing)

<a id="keywords-14"></a>
14. Quickstrike**: After this enemy engages a player, it immediately attacks that player if they are in hero form. (**See**: Quickstrike)

<a id="keywords-15"></a>
15. Ranged**: Attacks with ranged ignore retaliate. (**See**: Ranged)

<a id="keywords-16"></a>
16. Requirement (Resources)**: A card with the requirement keyword cannot be played unless each resource of the specified type is spent while paying for that card’s cost. (**See**: Requirement (Resources))

<a id="keywords-17"></a>
17. Restricted**: A player cannot control more than two restricted cards at a given time. (**See**: Restricted)

<a id="keywords-18"></a>
18. Retaliate X**: After a character with retaliate X is attacked, deal X damage to the attacker. (**See**: Retaliate X)

<a id="keywords-19"></a>
19. Setup**: Cards with setup start the game in play. (**See**: Setup)

<a id="keywords-20"></a>
20. Stalwart**: Characters with Stalwart cannot be stunned or confused. (**See**: Stalwart)

<a id="keywords-21"></a>
21. Steady**: A character with the steady keyword is not stunned or confused unless it has two stunned or confused status cards, respectively. (**See**: Steady)

<a id="keywords-22"></a>
22. Surge**: After a player reveals a card with surge, that player reveals an additional encounter card. (**See**: Surge)

<a id="keywords-23"></a>
23. Team-Up**: Cards with team-up cannot be played unless both characters listed by the keyword are in play. (**See**: Team-Up)

<a id="keywords-24"></a>
24. Teamwork ()**: After a minion with teamwork enters play and engages a player, if there is at least one other minion that shares the specified trait in play, the minion that just entered play activates against the player it is engaged with. (**See**: Teamwork ())

<a id="keywords-25"></a>
25. Temporary**: A card with temporary must be discarded from play at the end of the round. (**See**: Temporary)

<a id="keywords-26"></a>
26. Toughness**: When a character with toughness enters play, place a tough status card on it. (**See**: Tough/ Toughness)

<a id="keywords-27"></a>
27. Uses (X “type”)**: When a card with uses enters play, place X all-purpose counters from the token pool on that card. After the last all-purpose counter is removed from a card with uses *(and the effect resolves)*, discard that card. (**See**: Uses (X “type”))

<a id="keywords-28"></a>
28. Victory X**: When a card with victory X is defeated, add it to the victory display. (**See**: Victory X)

<a id="keywords-29"></a>
29. Villainous**: When a minion with villainous activates, give it a boost card. (**See**: Villainous)
