# MAIN SCHEME, MAIN SCHEME DECK

Main scheme is an encounter card type. The main scheme represents the villain’s primary objective.

<a id="main-scheme-main-scheme-deck-1"></a>
1. During step one of the villain phase, place the amount of threat indicated in the main scheme’s acceleration field *(bottom-right corner)* on that scheme. This value is modified by all active acceleration tokens and icons.

<a id="main-scheme-main-scheme-deck-2"></a>
2. If the amount of threat on a main scheme is equal to or greater than its target threat value, that main scheme is completed and the main scheme deck advances.
    <a id="main-scheme-main-scheme-deck-2-1"></a>
    - **If the villain completes the final stage of the main scheme deck, the villain wins the game.**
    <a id="main-scheme-main-scheme-deck-2-2"></a>
    - If the main scheme advances other than through having threat on it equal to or greater than its target threat value, that main scheme is **not** considered completed.

<a id="main-scheme-main-scheme-deck-3"></a>
3. When the main scheme deck advances, follow these steps: 1. Remove the top main scheme card from the game. Return all tokens (except acceleration tokens) that were on that card to the token pool and discard each card attached to it. 2. Resolve any “**When Revealed**” ability on the “A” side of the new top card of the main scheme deck. 3. Flip the top card of the main scheme deck to its “B” side, place threat on that card equal to its starting threat value, and resolve any “**When Revealed**” ability on that side of the card.

<a id="main-scheme-main-scheme-deck-4"></a>
4. When the main scheme deck advances, excess threat from the previous stage does not carry over to the new stage.

<a id="main-scheme-main-scheme-deck-5"></a>
5. When the main scheme deck advances, acceleration tokens on it carry over to the new stage.

<a id="main-scheme-main-scheme-deck-6"></a>
6. Main scheme cards cannot be discarded from play.
