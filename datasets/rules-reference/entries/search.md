# SEARCH

When a player is instructed to search for a card, the player is permitted to look at each of the cards in the searched area. If the player finds a card that satisfies the criteria of the search, the player adds that card to the game area indicated by the instructions on the search effect.

<a id="search-1"></a>
1. If a player finds multiple cards that satisfy the criteria of a search, the player chooses among those options.

<a id="search-2"></a>
2. Cards being searched are not considered to leave the searched area.

<a id="search-3"></a>
3. If any portion of a deck is searched, upon completion of that game step, game function, or card ability, shuffle that entire deck.

<a id="search-4"></a>
4. If a player is instructed to “search [their] collection” for a card, the player looks through all of their **Marvel Champions** cards outside of the current game for the specified card.
    <a id="search-4-1"></a>
    - They become the owner of that card until the end of the game.
