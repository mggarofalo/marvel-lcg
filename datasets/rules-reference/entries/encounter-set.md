# ENCOUNTER SET

An encounter set is a grouping of encounter cards.

<a id="encounter-set-1"></a>
1. There are four types of encounter sets: scenario- specific encounter sets, modular encounter sets, the Standard set, and the Expert set.

<a id="encounter-set-2"></a>
2. Encounter sets with the same name but different set icons are considered distinct sets.
