# Power of aspect generation candidate

This work activates the existing `doubleResourceFor` interpretation through the conditional resource quote. The printed icon remains the base output; its bonus is generated only if that source pays the named card's cost, including its own ability costs (rr:cost.3.1). Excess-only payment produces the base icon, including adjusted-zero costs; rulings 5e6ac90dc4187eef and b796aaa9fae1580b distinguish excess from a contribution allocated to the cost. A separate target's cost is not attributed to the initiating card; Make the Call is not claimed here.

When no allocation is submitted, the existing allocation search checks whether any legal allocation changes a selected conditional source's output. It permits a uniquely determined generation result, and otherwise rejects before payment. Other observable paid-resource declaration ambiguity still requires explicit input. Combined prices ask the hand-resource owner to quote the relevant component mask; unrelated resource generators retain their own conditions. The accepted hand quote is rechecked at contribution, including after earlier generators suspend.

Affordability previously counted only unconditional icons, so a matching Power as the sole source could make a payable action disappear. Card and ability admission now use the allocation search for this decision. Printed-only requirements continue to use printed sources. The work does not establish arbitrary target-cost attribution or change replay format. MARVEL-870 remains open.

The completed payment receipt now exposes the committed generated types separately from paid types, including excess. Access before completion throws, including during generator suspension. This is a narrow Rules-owned fact; it does not implement entry interrupts or spent-card responses.
