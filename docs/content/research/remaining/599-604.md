Agent implementation must test real `42004` against damage/prevention, tough, ranged, attacker leaving, nested and repeated attacks, suspend/restart, plus until-end-of-attack and end-of-phase controls. An open issue by itself is not evidence that current attack receipt cannot serve it. Harpoon `42025`/`42028` discard until an event then use **printed** cost as indirect damage; `42026` exhausts a character after indirect damage and `42027` attaches/searches or surges. **First bounded slice.** Implement three-form identity state and a real public Warren → Angel → Archangel path, then one discounted Aerial event with the correct independent once-per-phase response and save/restart. Negative controls: illegal fourth form/change, ordinary event, two same-phase responses, discount versus printed cost, later attack retaining no retaliate.
