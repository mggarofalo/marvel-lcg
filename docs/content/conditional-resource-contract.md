# Conditional resource quote prerequisite

Base: `f75ca018efea96e4b45dd8ecd074385b620677db`. This packet adds a synthetic conditional-output contract; it does not activate Power of aspect card text or claim MARVEL-878 resolved.

A resource source retains unconditional `Generates` and can name additional icons with a bitmask of qualifying cost components. The bonus exists only when the source itself has at least one allocated resource in a qualifying component. The mask is an engine choice, not a printed rule. Components identify costs of the card or its ability where appropriate: `rr:cost.3.1` says resources paid for an ability on a card count as paid for the card, and `rr:cost.5.1` lets the player divide resources between simultaneous costs. A separate target's cost must not be attributed to the initiating card without an engine-provided relationship. `rr:cost.4.1` distinguishes excess from paid resources; rulings `5e6ac90dc4187eef` and `b796aaa9fae1580b` distinguish wholly overpaid Power from one allocated to a cost.

The quote is a value copied through the prompt and session records, with null conditional fields omitted for existing unconditional sources. The allocation search, draft assessment and shared payment use the same source/component condition. Positive conditional payment without an allocation is explicitly unsupported, rather than inventing the player's division. `PossibleResources` is a local helper and excluded from JSON. The bonus is described beside the base in the native payment controls.
