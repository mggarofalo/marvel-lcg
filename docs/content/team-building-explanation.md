# Team-Building Exercise action meaning

The printed authority is `datasets/cards/cards.json` face `12024`: its Hero Action exhausts the support to play a card from hand that shares a trait with the hero, reducing that card's cost by 1. The existing `playSharedHeroTraitCard` operation owns legality, payment and play; this change supplies descriptions for that admitted operation without changing its decisions or execution.

The source offer names the action, the exhaustion cost and the hand/trait/reduction instruction. Its mandatory child prompt names the already exhausted source and asks for a matching card. Child offers retain engine-priced `CostOption` values, including target-specific attachment prices. Each one says that the shown price already includes the source's reduction of 1 and that a cost can't go below 0, so the copy never promises a price one less than the printed cost. Supported optional entry-counter interrupts are described as optional. Event effects use existing effect summaries when available. The cost caption identifies the offered amount as a payment ("Pay 0") on the choice's first line with the existing resource symbols; any explanation the choice carries renders on its own line below, so a compact caption cannot clip the price. This layout belongs to `DecisionCostLabel` and applies to every single-component costed choice whose engine label carries an explanation line (`LocalDecisionController.DescribeChoice` appends one), not only to Team-Building Exercise. Only the caption row takes the bold control weight; the explanation keeps body weight.

The view receipt test and the Godot copy test are labelled synthetic contracts: they prove those layers carry engine strings, not that the engine produces them.
