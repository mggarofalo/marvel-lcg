# Team-Building Exercise action meaning

The printed authority is `datasets/cards/cards.json` face `12024`: its Hero Action exhausts the support to play a card from hand that shares a trait with the hero, reducing that card's cost by 1. The existing `playSharedHeroTraitCard` operation owns legality, payment and play; this change supplies descriptions for that admitted operation without changing its decisions or execution.

The source offer names the action, the exhaustion cost and the hand/trait/reduction instruction. Its mandatory child prompt names the already exhausted source and asks for a matching card. Child offers retain engine-priced `CostOption` values, including target-specific attachment prices; they explain the reduction without promising the actual price is always one less than the printed cost. Supported optional entry-counter interrupts are described as optional. Event effects use existing effect summaries when available. The compact cost caption identifies the offered amount as a payment while retaining the existing resource symbols.

Focused content, view and Godot tests cover the source offer, zero and nonzero prices, an event, an attachment with differing host prices, optional entry, receipt wording and compact payment copy. On the prepared candidate, the focused lanes passed 35, 49 and 31 tests respectively. A compiled mutation removing the source effect detail failed the actual-card test, and a second mutation dropping the source title from the commit caption failed the same test; each passed again after restoration. Independent review and native interaction evidence remain necessary on the integrated revision; this document does not claim product acceptance.
