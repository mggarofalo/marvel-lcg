## Authority and review

For Justice removes additional threat if paid using a mental resource. The [current cost rules](../../datasets/rules-reference/entries/cost.md) distinguish resources paid for a card's ability (3.1), excess generated but not paid (4 and 4.1), and the player's division across simultaneous costs (5 and 5.1). The [vendored official FAQ](../../datasets/marvelcdb-faq/acquisition.json) explicitly treats Make the Call as paying for the selected ally, with the Power doubling only for a matching aspect; [vendored rulings](../../datasets/rulings/rulings.json) also distinguish that ally cost from an event's own resource cost.

The repair uses the same allocation-based feasibility for initiation, offered allies and answer validation, with the ally as cost owner. The matching Maria Hill and same-cost nonmatching Hulk control distinguish unconditional doubling; the test retains the actual allocation, ally entry, ownership, controller and spent-card assertions. For Justice's changed assertion describes the conditional quote; its mental-resource preference assertion is unchanged. Moving the default quote implementation to `NoCardAbilities` maintains the narrow-port policy; it is separate from the Make the Call behavioral fix.
